## 한 줄 요약

**미래 영상의 변화를 압축한 LAM latent와 action trajectory를 생성하는 VLA의 중간 표현을 서로 맞추어, 시각 동역학과 실제 action supervision이 양쪽 모델을 함께 개선하도록 학습한다.** 배포 시 미래 영상을 관측하거나 이미지 예측을 반복하는 planner가 아니라, 학습 중 표현을 정렬하는 방법이다.

## 문제의식

로봇 action label은 비싸지만 영상은 상대적으로 풍부하다. LAM은 현재·미래 프레임의 차이를 latent action으로 압축하고, 그 latent로 미래 프레임을 복원하는 과정에서 motion prior를 배운다. 기존 LAPA·Moto-GPT 같은 경로에서는 이렇게 만든 latent를 VLA의 pseudo-label로 사용하거나 사전학습 신호로 넘긴다.

이때 두 모델을 따로 학습하면 두 문제가 남는다. 첫째, 영상 복원에 유용한 배경·조명 변화까지 latent가 포착할 수 있어 실제 제어와의 대응이 약하다. 둘째, VLA가 frozen LAM의 품질에 묶이고, 그 latent를 실제 action label로 개선할 기회를 놓친다. LARA는 action DiT와 LAM에 gradient가 함께 흐르는 alignment objective를 추가한다.

<PaperFigure src="/lara/figure-02.png" alt="고정 LAM pseudo-label 학습과 LAM·VLA 공동 정렬을 비교한 Figure 2" caption="Figure 2 · PDF v2 p.2. 왼쪽은 frozen LAM에서 VLA로 향하는 supervision, 오른쪽은 두 학습 표현의 상호 정렬이다. frozen image encoder와 trainable LAM 전체를 혼동하지 않는다." />

저자의 해석은 두 방향이다. VLA의 실제 action supervision이 LAM을 제어에 관련된 변화에 집중시키고, LAM의 forward reconstruction이 action 표현에 동작 이후의 시각적 효과를 반영하도록 유도한다. 이 해석을 지지하는 성공률·attention·ablation은 있지만, 물리적 타당성이나 인과적 표현을 수학적으로 보장하는 것은 아니다.

## Dataset

### 논문의 데이터 계약

LAM과 policy의 주 실험은 OXE의 **single-arm end-effector control trajectory subset**을 사용한다. LAM pretraining은 action label을 objective에 쓰지 않고 영상 쌍을 학습한다. joint pretraining은 유효한 action label이 있는 robot demonstration을 사용한다. human/internet video는 방법의 동기와 적용 가능성으로 제시되지만, 보고된 OXE-constrained 결과를 대규모 human-video 추가 효과로 해석할 수는 없다.

Figure S.1에서 Fractal 16.9%, BC-Z 10.7%, FMB 10.2%, Bridge 8.27%, Kuka 7.66%, Stanford Hydra 6.44%, Language Table 6.32% 등 여러 출처가 보인다. Appendix A.3은 각 subset을 동일 확률로 뽑는 balanced sampling을 설명한다. 그림의 데이터 구성 비율과 학습 때의 sampling probability는 같은 의미가 아니다. 전체 episode/frame 수, 정확한 OXE version, filtering 코드의 완전한 inventory는 이 PDF에서 제공하지 않는다.

<PaperFigure src="/lara/figure-s1.png" alt="OXE subset의 출처와 비율을 표시한 Figure S.1" caption="Figure S.1 · PDF v2 p.14. 작은 subset까지 전체 출처 분포를 보존했다. 분포 그림만으로 episode 수나 실제 batch sampling 확률을 복원하지 않는다." />

| --- | --- |
| LAM pretraining | OXE 영상 쌍, stride 5. quantized latent로 미래 프레임 복원 |

Appendix D의 **109k video trajectory·73k RT-1 expert trajectory**는 원래 Moto-GPT pipeline 설명이다. LARA의 비교 실험이 그 전체 데이터를 그대로 사용했다는 뜻이 아니다. 저자들은 효율을 위해 Fractal만 사용하는 수정 protocol을 명시한다. 개선된 LAM은 추가 joint pretraining을 거쳤으므로 tokenizer 학습 계산량까지 같게 맞춘 비교로 보기도 어렵다.

## Method

### 1. 영상 변화의 latent action

현재 영상 `I_t`, 미래 영상 `I_(t+C)`, 그 사이 action chunk `A_t`, instruction `L`, state `s_t`를 사용한다. IDM은 영상 쌍을 continuous latent `z_t`로 압축한다. VQ는 이를 discrete code `z_t^q`로 만들고, FDM은 현재 영상과 그 code로 미래 영상을 복원한다.

```text
z_t        = IDM_phi(I_t, I_(t+C))
z_t^q      = Quant_phi(z_t)
I_hat      = FDM_phi(I_t, z_t^q)
L_LAM      = future-image reconstruction + VQ / commitment terms
```

원문의 Eq. (3)은 squared reconstruction error와 stop-gradient가 걸린 두 VQ 항으로 구성된다. 미래 프레임 복원은 latent가 실제 변화를 담도록 하지만, 그 변화가 곧 robot action 자체임을 보장하지는 않는다. VQ vocabulary 128은 로봇 제어 DoF 수가 아니라 visual motion codebook의 크기다.

### 2. action chunk의 flow matching

VLM feature와 state를 condition `c_t`로 사용한다. noise `epsilon`과 ground-truth action chunk 사이를 보간한 `A_t^tau`에서 velocity를 예측한다. 원문의 Eq. (1)–(2)를 같은 기호로 풀면 다음과 같다.

```text
A_t^tau    = tau * A_t + (1 - tau) * epsilon
target_v   = A_t - epsilon
L_ACT      = E[tau, epsilon] ||v_theta(A_t^tau, c_t) - target_v||^2
A^(tau+1/K)= A^tau + (1/K) * v_theta(A^tau, c_t)
```

추론은 Gaussian action noise에서 시작해 Euler integration으로 action chunk를 만든다. 논문은 diffusion-based라는 넓은 용어를 쓰지만, 여기서 구현·수식의 구체적인 action generator는 flow matching이다. `K`번 integration과 실제 로봇의 control Hz를 혼동하지 않는다.

### 3. LAM과 action DiT의 continuous 표현 정렬

DiT의 중간 hidden feature를 `h_t`, 차원을 맞추는 projector를 `f_psi`라고 하면 핵심 objective는 다음과 같다.

```text
L_LARA = - E[A_t, epsilon, tau] CosSim(z_t, f_psi(h_t))
L      = L_ACT + w1 * L_LARA + w2 * L_LAM
```

alignment target은 **양자화 전 continuous latent**다. discrete code ID를 분류하도록 VLA head를 바꾸는 방법이 아니다. frozen target을 사용하는 representation alignment와 달리 LAM latent도 joint training 중 갱신된다. 두 branch의 표현에 gradient가 흐르며, FDM reconstruction은 LAM이 action branch에만 맞추다가 시각 동역학 정보를 잃지 않도록 함께 남긴다.

원문 Appendix A.2는 action chunk **마지막 timestep의 hidden token**을 미래 프레임의 latent와 맞춘다고 명시한다. GR00T 계열은 DiT `L−2` 위치, π0.5는 마지막 layer가 유리했다. 이는 action이 끝난 뒤의 시각적 효과와 trajectory 표현을 연결하려는 선택이며, layer 번호를 모든 architecture에 고정하는 규칙은 아니다.

<PaperFigure src="/lara/figure-03.png" alt="IDM·VQ·FDM과 VLA DiT alignment를 연결한 LARA method diagram" caption="Figure 3 · PDF v2 p.4. LAM pretraining은 영상 쌍을 reconstruction으로 학습한다. joint training에서는 DiT hidden feature와 continuous z를 projector로 정렬하고 action·LAM loss를 함께 유지한다." />

### 4. 학습과 배포의 정보 흐름

학습 sample에는 instruction·현재 state/RGB·action chunk·미래 RGB가 있다. 현재 관측으로 policy를 조건화하고, action chunk에 noise를 섞어 flow target을 만들며, 현재/미래 RGB로 LAM target을 계산한다. 세 loss를 합쳐 trainable modules를 갱신한다.

배포에서는 현재 RGB·instruction·state만으로 VLA feature를 만들고 action noise를 반복 적분한다. 공개 `get_action()`은 LAM forward나 미래 RGB를 호출하지 않는다. 따라서 inference 때 실제 미래를 미리 알아야 하는 구조는 아니다. 다만 공개 wrapper마다 action chunk에서 몇 step을 실행하는지는 별도의 runtime 계약이며, 이 논문은 latency/FLOPs/Hz를 체계적으로 비교하지 않는다.

## Model Architecture

| 구성요소 | 원문 Appendix A.1 / Table S.1 기준 역할과 설정 |
| --- | --- |
| LAM visual encoder | frozen pretrained ViT, 현재·미래 patch embedding 생성 |
| M-Former | transformer 4 layers, learnable query 8개. 영상 차이를 query feature로 요약 |
| VQ | codebook 128 entries. continuous latent와 discrete token을 구분 |
| FDM decoder | ViT 12 layers, hidden 768, heads 12. 현재 영상과 quantized latent로 미래 RGB 복원 |
| VLM | frozen Eagle-2. vision/language feature 추출 |
| Adapter | trainable self-attention 1개와 LayerNorm |
| Embodiment interface | state/action encoder와 action decoder는 embodiment-specific MLP. 최대 embodiment ID 64, state dim 64, action dim 32 |
| Action DiT | 본문 기본 설계 16 layers, self/cross attention을 사용. noisy action과 state를 VLM feature로 조건화 |
| Alignment projector | MLP로 action hidden feature를 LAM latent 공간에 투영. GR00T 실험 `L−2` |

<PaperFigure src="/lara/table-s1.png" alt="LAM·VLA의 query 수, layer 수, codebook, state/action 크기를 정리한 Table S.1" caption="Table S.1 · PDF v2 p.13. 본문 기본 모델의 설정이며, 모든 pretrained GR00T-N1.6/π0.5 backbone이 같은 16-layer 구조라는 뜻은 아니다." />

현재 tokenizer YAML에서는 M-Former의 8×768 feature를 down-project하여 `8×32` continuous code embedding을 만든다. full release의 projector target은 이를 펼친 256차원이다. ViT-MAE-Large encoder feature 폭은 1024, decoder는 224×224·patch 16·196 patches로 설정한다. 이 추가 수치는 **공개 config**에서 확인한 것이며, 논문 Table S.1이 모든 tensor dimension을 직접 명시한 것은 아니다.

## Training Recipe

| 단계 | 원문 학습 조건 | objective / 학습 범위 |
| --- | --- | --- |
| LAM pretraining | 350k steps, global batch 512, 4 A100, frame stride 5 | LAM reconstruction/VQ. ViT encoder frozen, motion encoder·quantizer·decoder 학습 |
| DiT-only pretraining | 200k steps, global batch 384, 4 A100, action horizon 16 | `L_ACT`만. full과 기본 optimizer 조건을 맞춘 대조군 |
| Full joint pretraining | 200k steps, global batch 384, 4 A100, horizon 16 | pretrained LAM + scratch-initialized action DiT. `w1=w2=0.01`, action/latent/LAM 공동 학습 |
| Target post-training | 약 20k steps, GR1만 50k, global batch 384, 4 A100 | target demo로 joint optimization. DiT-only/full/GR00T baseline에 공통 protocol 설명 |
| GR00T-N1.6 enhancement | public pretrained N1.6 + OXE-pretrained LAM에서 시작 | target post-training에 LARA objective를 추가, `w1=w2=0.01` |
| π0.5 enhancement | LIBERO 20k steps, π0.5 post-training recipe | 마지막 layer alignment, `w1=w2=0.01`. `L−2`도 별도 비교 |

원문 공통 AdamW peak LR `1e-4`, cosine decay, weight decay `1e-5`다. 현재 release의 batch/steps/weight decay·optimizer schedule은 아래에서 별도 대조한다. 논문에 없는 gradient accumulation·precision·augmentation 세부 사항을 현재 config에서 가져와 원문 recipe인 것처럼 채우지 않는다.

## Experiments and Results

표의 수치는 success rate `%`다. 차이 `Δpp`는 퍼센트포인트이며, 원문의 Improvement 행은 대체로 `(new−old)/old × 100`의 **상대 개선율**이다. 예를 들어 LIBERO 84.4→88.6은 +4.2pp, 상대 +5.0%다. 초록의 약 10%/5%/15%를 모든 task에서의 절대 성공률 상승으로 읽지 않는다.

### C: 실물 설정과 stage metric의 불일치

G1의 tomato/basket·bottle/cup 초기 위치는 10cm×10cm 영역에서 randomize한다. head camera의 시야를 넓히려고 머리 2DoF도 제어하며 task마다 teleoperation demonstration 50개를 수집한다. 머리·손·팔을 합친 28차원 policy다. camera 제품이 depth를 지원하더라도 이 실험에서 depth 관측을 사용했다고 쓰여 있지는 않다.

<PaperFigure src="/lara/figure-s3.png" alt="D455·G1 양팔·Inspire Hands·머리 motor의 실물 배치" caption="Figure S.3 · PDF v2 p.15. 고정한 상체의 시각 manipulation 설정이다. 28DoF 구성과 RGB observation을 확인한다." />

<PaperFigure src="/lara/figure-s4.png" alt="G1의 pick-and-place와 pouring 프레임 열" caption="Figure S.4 · PDF v2 p.16. demonstration instruction과 여러 동작 단계를 보여준다. 성공 예시의 frame 열을 전체 trial 성공률과 같은 의미로 읽지 않는다." />

Appendix C는 Place/Pour를 조건부 성공률로 설명하지만 PDF에 인쇄된 Eq. S.8/S.9는 다음과 같다.

```text
S.8: SR_Place = (SR_Full - SR_Pick) / SR_Pick
S.9: SR_Pour  = (SR_Full - SR_GL * SR_GR) / (SR_GL * SR_GR)
```

이 식은 성공한 grasp를 조건으로 하는 성공 확률이라는 정의와 일치하지 않는다. DiT-only의 Pick=74%, Full=58%를 S.8에 넣으면 음수가 나오지만 Table 2의 Place는 78.4%이며 58/74의 비율과 맞는다. **원문 수식과 표의 값을 구분해 보고**하며 수식을 조용히 수정하지 않는다.

Pour에는 좌우 grasp의 주변 성공률을 곱하는 독립 가정도 명시되어 있다. 그러나 표의 Pour는 S.9에서 재현되지 않으며 일반적인 `Full / (GL×GR)`로도 모든 행을 복원할 수 없다. 실제로 두 grasp가 함께 성공한 joint trial 수가 없어 조건부 분모를 주변 성공률만으로 확정할 수 없다. 비교의 주축은 50 trial에 대한 Full로 삼고, stage metric을 재현하려면 raw trial 기록이나 저자 확인이 필요하다.

Figure 1의 G1 Real 막대는 full 58→80, post-training 76→84.5지만 Table 2의 두 task Full 평균은 56→74와 72→76이다. teaser의 84.5도 Table 2의 Pick/Place Full 84.0과 다르다. 이미지는 원문을 유지하며 집계 결과는 상세 표에 고정했다.

### D: LARA-LAM을 Moto-GPT에 제공하기

원래 Moto-GPT는 tokenizer pretraining, latent-only VLA pretraining, latent＋action co-fine-tuning의 세 단계다. LARA 비교는 자체 pretrained LAM으로 첫 단계를 대체하고 Fractal에서 나머지 두 단계를 수행한다. LARA-LAM에는 추가 joint pretraining이 있다. Table 3은 이렇게 만든 pseudo-label의 가치를 평가하며 단일 stage·동일 계산량 비교는 아니다.

공개 구현의 현재 형태를 설명하는 차이이며 원문 결과를 바꿔 해석하는 근거는 아니다. tokenizer YAML에는 `。/`로 시작하는 dataset placeholder도 있으므로 그대로 실행하지 말고 dataset·model·norm-stat의 실제 경로를 지정한다.

## 한계와 주의

1. **효과는 조건에 의존한다.** N1.6 일부 task는 하락하고 π0.5의 L−2는 크게 악화한다. layer·loss weight를 조정해야 한다.
2. **데이터 효과의 근거를 구분한다.** 사람 영상을 이용할 수 있는 설계와 OXE subset에서 측정한 효과는 다르다. 전체 episode 수·filter·mixture를 완전히 복원할 근거도 부족하다.
3. **실물 적응에는 추가 시연을 사용한다.** task당50demo·50trial·좁은 위치 randomization·두 task·gantry 고정 조건을 zero-shot generalist humanoid의 근거로 확대하지 않는다.
4. **지표 설명에 불일치가 있다.** 조건부 stage 수식·teaser 집계·최적 w2 값을 구분해 기록했다. Full 성공을 주로 읽으며 저자 확인 없이 stage 분모를 확정하지 않는다.
5. **runtime 세계 모델은 아니다.** 미래 이미지 reconstruction으로 학습을 regularize한다. 물리 simulator·MPC·test-time imagined rollout의 성능을 평가한 것은 아니다.
6. **모델 실험을 재현하지 않았다.** source/config·PDF 대조, crop·문서·사이트 검증을 수행했다. weight 로드·GPU 학습·simulation 성공률·G1 실행의 재현 결과는 포함하지 않는다.

## 기억할 점

LARA의 핵심은 **action label로 LAM도 갱신하는 양방향 학습 계약**이다. 추가 image prediction을 robot runtime에 반드시 넣는 설계가 아니므로 기존 flow-based VLA에 training objective로 연결할 수 있다. 다만 plug-and-play가 무조정·일관된 개선을 뜻하지는 않는다. target frame의 시간 대응, layer 위치, 보조 loss 비중, 공개 구현과 원문 recipe 차이가 결과를 좌우한다.
