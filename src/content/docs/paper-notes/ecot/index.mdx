# ECoT Reasoning Family

## 범위

이 문서는 2026-07-14 기준 공개된 robot/VLA embodied reasoning 계열을 시간 순서와 기술 발전 축으로 정리한다. “ECoT 계열”은 좁게는 Zawalski et al.의 Embodied Chain-of-Thought, 넓게는 robot policy가 action 전에 intermediate reasoning, visual goal, spatial trace, depth token, 또는 reasoning-supervised representation을 사용하는 흐름을 포함한다.

## 기술 발전 축

### 1. Explicit Text Reasoning

ECoT의 출발점은 action prediction 전에 robot-specific reasoning text를 생성하는 것이다. Pure semantic subtask만으로는 부족해서, object bounding box, end-effector position, motion description처럼 observation과 robot state에 grounded된 reasoning을 포함한다. 장점은 성능과 interpretability이고, 단점은 annotation cost와 slow autoregressive inference다.

### 2. Reasoning Data Scaling

RAD는 action label이 없는 human video에도 reasoning annotation을 붙여 policy generalization에 쓸 수 있다는 방향을 연다. 이 branch의 핵심은 robot demonstration이 부족할 때, reasoning label을 action-free data에서 scale할 수 있는지다.

### 3. Visual / Spatial CoT

CoT-VLA와 MolmoAct는 reasoning의 형식을 language에서 visual/spatial representation으로 옮긴다.

| 논문 | reasoning 형식 |
| --- | --- |
| [CoT-VLA](./cot-vla-visual-chain-of-thought/) | future image frames as visual goals |
| [MolmoAct](../molmo/molmoact-action-reasoning-models/) | depth perception tokens + image-space visual reasoning trace |
| [MolmoAct2-Think](../molmo/molmoact2-real-world-deployment/) | adaptive depth tokens for changed scene regions |

이 흐름은 language CoT보다 robot control에 가까운 중간 표현을 사용한다는 점에서 중요하다.

### 4. Training-Only Reasoning

ECoT-Lite와 ERVLA는 explicit CoT를 test-time에 항상 생성해야 하는지 의심한다. ECoT-Lite의 reasoning dropout은 Full ECoT와 비슷한 LIBERO average를 내면서 inference에서는 reasoning을 생략할 수 있음을 보인다. ERVLA는 대규모 데이터에서 autoregressive CoT prefix가 compounding error와 unstable reasoning-action coupling을 만들 수 있다고 보고, CoT를 representation-shaping supervision으로 재정의한다.

### 5. Latency / Deployment

| 접근 | 아이디어 |
| --- | --- |
| Fast ECoT | 기존 ECoT를 유지하고 cache/reuse/parallelization/async scheduler로 빠르게 함 |
| ECoT-Lite | reasoning을 training signal로 쓰고 test-time reasoning을 제거 |
| MolmoAct2 | continuous flow expert와 KV conditioning으로 action generation을 빠르게 만들고, depth reasoning은 adaptive하게 수행 |
| ERVLA | CoT decoding 없이 direct action prediction |

## 읽는 순서

1. ECoT original로 “robot-specific CoT가 무엇인가”를 잡는다.
2. ECoT-Lite로 “이득이 test-time reasoning 때문인가 training signal 때문인가”를 분해한다.
3. MolmoAct로 “language reasoning 대신 spatial trace/depth reasoning을 쓰는 route”를 본다.
4. MolmoAct2로 deployment latency, flow expert, adaptive depth reasoning까지 확장한다.
5. ERVLA, RoboPIN, Pinocchio로 scale, grounding, faithfulness 문제를 검토한다.

## 한계와 주의

- “Reasoning trace가 보인다”는 것과 “그 trace가 action decision의 causal explanation이다”는 다르다.
- Text CoT, visual future, depth token, trajectory trace는 모두 중간 supervision이지만, control loop에서 쓰이는 방식과 latency가 크게 다르다.
- Benchmark별 robot embodiment, action representation, trial count, success metric이 달라 수치를 직접 단순 비교하면 안 된다.
