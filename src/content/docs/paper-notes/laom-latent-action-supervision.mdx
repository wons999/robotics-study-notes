## 한 줄 요약

**배경·색·camera 변화가 섞인 영상에서는 observation-only latent가 control에 필요한 action을 제대로 표현하지 못할 수 있으며, 소량의 실제 action supervision을 LAM 학습 때부터 넣는 것이 사후 decoder 학습만으로 쓰는 것보다 효과적이다.**

<PaperFigure src="/laom/figure-01.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Figure 1: 128 labeled trajectory에서 normalized return 약0.44. task 성공률44%가 아니다." caption="Figure 1 · PDF v5 p.1. 128 labeled trajectory에서 normalized return 약0.44. task 성공률44%가 아니다." />

## 문제의식

IDM이 current/future observation을 보고 latent action을 추출하고 FDM이 이를 이용해 next observation을 복원하면, latent가 실제 action을 담을 것이라는 기대가 있다. 그러나 observation 변화는 배경 영상·조명·camera motion 같은 nuisance에도 설명된다. 특히 실제 action과 함께 변하는 distractor는 reconstruction loss만으로 분리하기 어렵다.

이 연구는 대형 VLA·실물 manipulation 모델을 발표하는 논문이 아니다. Distracting Control Suite(DCS)의 통제된 네 환경에서 기존 LAPO pipeline의 실패, 구조 개선 LAOM, labeled supervision을 추가한 LAOM+supervision을 비교하는 진단 연구다.

## Dataset

expert는 proprioceptive state로 학습하며 distractor 없는 환경에서 rollout한다. cheetah/walker/hopper는 CleanRL PPO 1M steps, humanoid는 Stable Baselines SAC 약100k steps로 학습한다. 이후 같은 task dynamics에 distractor를 추가한 RGB video와 action을 저장한다. action은 observation-only pretraining에서는 loss에 쓰지 않고 정해진 small-label subset에서만 supervisory target이 된다.

<PaperFigure src="/laom/table-01.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Table 1: expert rollout 평균 return과 데이터 크기: task당 약58GB. 실제 데이터 전체를 이 검토에서 다운로드하지 않았다." caption="Table 1 · PDF v5 p.15. expert rollout 평균 return과 데이터 크기: task당 약58GB. 실제 데이터 전체를 이 검토에서 다운로드하지 않았다." />

dataset 파일은 trajectory별 `obs`, `actions`, `states` 및 `img_hw`·domain/task metadata를 갖는 HDF5다. loader는 history를 첫 frame으로 padding해 3-frame stack을 만들고 episode 경계 안에서 current·next·future pair를 샘플링한다. simulator state가 저장되어 있다고 image-based latent policy가 state를 입력으로 받는 것은 아니다.

128/5000은 **2.56%**, 논문은 약2.5%라고 표현한다. 이 budget을 LAM과 decoder가 공유하므로 labels를 각 단계마다 새로 128개씩 더 쓴 것이 아니다. 하지만 모든 action을 쓰는 diagnostic probe로 hyperparameter를 선택한 부분은 별도의 oracle 정보 접근이며 완전한 label-blind selection과 구분해야 한다.

## 방법론

### 기존 LAPO의 세 단계

첫째, `z = IDM(o_t, o_t+1)`와 `FDM(o_t, z)`를 reconstruction objective로 학습한다. 둘째, dataset을 latent pseudo-label로 relabel해 current observation만 보는 policy가 latent를 모방한다. 셋째, 고정된 policy representation에서 작은 labeled dataset으로 latent→real action decoder를 학습한다. 논문은 이 전체 순서를 유지하고 첫 LAM을 개선한다.

<PaperFigure src="/laom/figure-03.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Figure 3: LAM 학습 → latent behavior cloning → labeled action decoding." caption="Figure 3 · PDF v5 p.2. LAM 학습 → latent behavior cloning → labeled action decoding." />

### LAOM: 병목·target·augmentation을 바꾼다

원래 quantized bottleneck을 제거하고 **8192-dimensional continuous latent**를 사용한다. current와 `t+k` future를 shared ResNet encoder로 표현하며 `k`를 1–10에서 샘플링해 multi-step dynamics 정보를 얻는다. pixel reconstruction 대신 encoder feature를 예측하고 stop-gradient/EMA target을 사용한다. random shift·rotation·perspective augmentation은 LAM 학습에만 적용한다.

<PaperFigure src="/laom/figure-04.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Figure 4: LAPO의 분리 encoder·quantization·pixel FDM에서 shared encoder·큰 continuous latent·feature FDM으로 변화." caption="Figure 4 · PDF v5 p.3. LAPO의 분리 encoder·quantization·pixel FDM에서 shared encoder·큰 continuous latent·feature FDM으로 변화." />

큰 latent는 nuisance를 완전히 제거하는 bottleneck이 아니다. 정보를 충분히 보존한 뒤 action-relevant 부분을 labeled objective로 정렬하려는 접근이다. quantization이 모든 로봇 문제에서 나쁘다는 결론도 아니다. 위 benchmark와 architecture에서 병목의 손해를 관찰한 것이다.

**공식 코드의 시간 target을 주의해야 한다.** `DCSLAOMInMemoryDataset`은 `o_t`, `o_t+1`, `o_t+k`, `a_t`를 반환한다. `train_laom_labels.py`의 IDM은 current/future=`t+k`를 받지만 feature reconstruction target은 **`target_lapo.encoder(next_obs)` 즉 t+1**이다. variable future interval과 FDM prediction horizon을 같은 k라고 단정하지 않는다. latent BC의 relabel 단계는 adjacent current/next pair를 사용한다.

### LAOM+supervision

작은 labeled batch의 latent에 linear head를 붙여 `a_t`를 MSE로 예측한다. total은 reconstruction + lambda·action supervision이며 actual action loss gradient가 LAM에도 흐른다. 이 label은 이후 action decoder에서 사용할 동일 subset이다. diagnostic action probe의 `.detach()`와 달리 representation 자체를 action-relevant하게 바꾸는 학습 신호다.

paper는 supervision weight 일반 task **0.01**, cheetah **0.001**을 사용한다. 현재 example YAML은 **0.001**이 기본값이므로 이를 모든 paper 실험값으로 대체하지 않는다. 감독되는 action은 `a_t` 한 벡터이며 k-step action chunk 전체가 아니다.

## 모델 구조와 Training Recipe

| 단계 | 설정 |
| --- | --- |
| 공통 | single H100, PyTorch bf16 AMP. ResNet 계열 image encoder·ReLU MLP; residual block 2 |
| LAM | Adam, weight decay0, 10 epochs, batch512, lr1e-4, warmup3 epochs, encoder scale6, latent8192, IDM/FDM hidden1024, EMA tau.001·매 update |
| Supervision | labeled batch128, linear latent→action head. lambda .01 / cheetah .001 |
| Latent BC | AdamW, weight decay0, 10 epochs, batch512, encoder scale32, lr1e-4, augmentation 없음 |
| Action decoder | AdamW, hidden256 MLP, batch512, 2500 updates, lr3e-4, evaluation25 episodes |

공개 MLP는 latent/condition feature를 residual layer에 반복 주입한다. target encoder는 별도 projection head 없이 observation embedding을 제공한다. reconstruction은 기본 MSE이며 cosine-loss 옵션은 별도다. Appendix는 supervised setting에서 stop-gradient만으로 충분하다고 논의하지만 공개 script/YAML에는 target encoder·EMA 옵션도 남아 있다.

논문 Appendix D의 cosine warmup schedule 설명과 달리 공개 training script는 `linear_annealing_with_warmup`을 호출한다. `src/scheduler.py`의 실제 함수는 warmup 후 **linear decay**이므로 이름만 보고 cosine으로 기술하지 않는다.

## 실험과 결과

### Quantization·multi-step·augmentation: 8배의 의미

Figure 5에서 action linear-probe median MSE는 quantized LAPO distractor 있음/없음 **29.17/16.41**, quantization 제거 **22.09/2.55**다. nuisance가 없을 때도 이 bottleneck의 손해가 크지만, 제거만으로 distractor 문제를 해결하지 못한다.

<PaperFigure src="/laom/figure-05.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Figure 5: FSQ 유무·distractor 유무의 action-probe MSE. 낮을수록 좋다." caption="Figure 5 · PDF v5 p.4. FSQ 유무·distractor 유무의 action-probe MSE. 낮을수록 좋다." />

Figure 6의 누적 변경은 **22.09 → 9.54(multi-step) → 3.89(latent8192) → 5.22(feature FDM) → 2.74(augmentation)**다. feature prediction만 추가한 단계는 probe MSE가 오히려 악화한다. 최종 22.09/2.74≈8.06이 “8배 개선”이며 **reward나 task success 8배가 아니다**. distractor 없는 결과는 2.55→1.93이다.

<PaperFigure src="/laom/figure-06.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Figure 6: 각 변경의 누적 probe MSE와 8배 계산의 분모·분자." caption="Figure 6 · PDF v5 p.5. 각 변경의 누적 probe MSE와 8배 계산의 분모·분자." />

### Return과 action label의 위치

LAOM은 distractor 있는 control return에서 LAPO를 대략 두 배 개선하지만 small-label BC나 supervised IDM보다 항상 좋지 않다. action을 마지막 decoder에서만 주는 기존 경로와 LAM부터 주는 경로 사이에 차이가 남는다.

<PaperFigure src="/laom/figure-07.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Figure 7: distractor 유무의 normalized return vs label budget." caption="Figure 7 · PDF v5 p.5. distractor 유무의 normalized return vs label budget." />
<PaperFigure src="/laom/figure-08.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Figure 8: 네 task의 LAOM+supervision / LAOM / LAPO / IDM / BC curve." caption="Figure 8 · PDF v5 p.6. 네 task의 LAOM+supervision / LAOM / LAPO / IDM / BC curve." />

128 labels에서 LAOM+supervision은 평균 normalized return 약**0.44**다. full-action BC를 1로 정규화했으므로 BC 수준의 약44%를 회복한 것이며 “44%의 task를 성공”했다는 뜻이 아니다. abstract는 downstream 개선을 **4.2배**, 본문은 **4.3배**로 기술한다. 동일한 underlying comparison의 표현 차이를 남기고 임의의 새 정밀값을 만들지 않는다.

<PaperFigure src="/laom/table-03.png" alt="LAOM — Distractors와 Latent Action Supervision 원문 Table 3: full-action BC return: distractor 있음 cheetah823/walker749/hopper253/humanoid428. expert return이 normalizer가 아니다." caption="Table 3 · PDF v5 p.16. full-action BC return: distractor 있음 cheetah823/walker749/hopper253/humanoid428. expert return이 normalizer가 아니다." />

Table 1 expert return과 Table 3 normalizer는 서로 다르다. 예를 들어 humanoid expert dataset 평균은 617.22지만 distractor full-BC normalizer는 428이다. 큰 normalized return이 expert-level 성공을 뜻한다고 읽으면 안 된다.

Figure 9(a)의 new-background action probe에서는 supervised LAOM이 IDM보다 낮은 MSE를 보인다. (b/c)는 latent 8192→64로 줄일 때 unsupervised LAOM return이 상대적으로 **63.1% 감소**, supervised는 **16.2% 감소**함을 보인다. 64는 continuous representation dimension이며 discrete vocabulary 64개가 아니다.

## Appendix Notes

Appendix A/B는 related-work·추가 representation/bottleneck/transfer 실험, C는 expert dataset 생성, D는 구현·runtime, E는 evaluation normalizer, F는 모든 method hyperparameter를 제공한다. 위 15개 그림·10개 표에 각각 연결했다.

LAPO 원래 논문의 discrete minimal-action setting과 이번 continuous-control adaptation을 구분한다. 공개 baseline config도 latent8192·future offset10을 사용하므로 단순히 원래 Procgen LAPO 그대로라고 설명할 수 없다. ground-truth probe를 이용한 tuning과 같은 subset의 supervision/decoder 재사용도 각각 별도로 기록한다.

## 한계와 주의

- DCS 네 task·조정된 noise scale·expert-generated video의 결론이며 실제 인터넷 영상 전체에 대한 정리는 아니다.
- 큰 continuous latent가 universal optimum이라는 결론이나 quantization의 보편적 실패 주장은 없다.
- 소량 label의 단계별 재사용은 공정하지만 full-label diagnostic tuning은 additional information access다.
- return·probe MSE·relative decrease는 task success와 다른 단위다.
- action supervision의 경험적 중요성을 보여주며 모든 distractor에서 supervision이 필수라는 수학적 impossibility theorem은 아니다.

## Citation Trail

[LAPO(Learning to Act without Actions)](https://arxiv.org/abs/2312.10812)는 기반 observation-only IDM/FDM→latent BC→action decoder pipeline이다. VPT는 먼저 labeled IDM으로 video에 action pseudo-label을 만드는 다른 경로다. Genie-style model은 controllable world-model 방향으로 연결되며, video prediction을 control representation과 동일시하지 않아야 한다.

[LAPA](../lapa-latent-action-pretraining/)·[Moto](../moto-latent-motion-tokens/)의 frozen tokenizer와 [UniVLA](../univla-task-centric-latent-actions/)의 task-conditioned 분리는 nuisance에 대응하는 서로 다른 선택이다. [LARA](../lara-latent-action-representation-alignment/)는 실제 action objective와 LAM을 공동 정렬하는 방향으로 연결된다. [전체 안내](../latent-action-models/)에서 supervision이 어느 단계에 들어가는지 비교한다.
