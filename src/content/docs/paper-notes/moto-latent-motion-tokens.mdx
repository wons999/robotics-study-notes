## 한 줄 요약

**영상 변화의 discrete motion token을 언어처럼 autoregressive하게 예측하는 Moto-GPT를 학습하고, 실제 action fine-tuning에서도 motion prediction을 함께 유지해 learned motion prior를 제어로 연결한다.**

<PaperFigure src="/moto/figure-01.png" alt="Moto — Latent Motion Tokens 원문 Figure 1: 영상 → motion tokenizer → next-motion prediction → 실제 action의 흐름과 benchmark 요약." caption="Figure 1 · PDF v4 p.1. 영상 → motion tokenizer → next-motion prediction → 실제 action의 흐름과 benchmark 요약." />

## 문제의식

video를 frame prediction target으로 쓰면 배경·appearance에 많은 연산을 사용할 수 있다. 실제 action의 robot-specific 차원을 직접 예측하면 human video를 동일하게 사용하기 어렵다. Moto는 두 프레임 사이의 변화만 적은 수의 token으로 추출해, language instruction 아래 motion sequence prediction을 pretraining objective로 삼는다.

핵심은 tokenizer만 만드는 것이 아니라 **pretraining과 action fine-tuning을 연결하는 objective·attention mask**다. [LAPA](../lapa-latent-action-pretraining/)처럼 downstream에서 latent prediction head를 버리는 경로와 비교할 수 있다.

## Dataset

OXE의 109k video trajectory를 사용한다. RT-1, Bridge, Task-Agnostic Play, Jaco Play, Cable Routing, RoboTurk, NYU VINN, Austin VIOLA, Berkeley UR5, TOTO의 10개 출처다. tokenizer와 Moto-GPT pretraining에는 robot action label을 쓰지 않지만 language·기존 encoder 지식은 사용한다.

| 구간 | 데이터·label |
| --- | --- |
| SIMPLER adaptation | RT-1의 약 73k action-labeled expert trajectory. LAPA의 100개 sim adaptation과 직접 비교 불가 |
| CALVIN | ABC play data로 tokenizer 학습. language annotation 있는 약 18k trajectory(약 35%)로 pretraining·action adaptation |
| 실물 | 3 task × 30 demo = 90. OXE에 이를 섞어 추가 pretraining 후 action fine-tuning |
| Human 확장 | SSV2 motion 관련 105k 영상 filtering + OXE 109k. Figure 9의 Move Near 결과에 사용 |

공개 loader는 LMDB에서 RGB·language·action·latent token을 읽고 episode boundary padding과 attention/loss mask를 구성한다. dataset별 fps 차이를 sampling skip으로 보정한다. video trajectory 수와 transition/token 수는 같은 단위가 아니다.

## 방법론

### 1. Latent Motion Tokenizer

frozen ViT의 current/future patch feature를 M-Former가 받아 **8개 learned query**에 변화를 모은다. 이를 128-entry codebook의 32차원 embedding으로 quantize한다. decoder는 current image patch에 quantized motion을 조건으로 넣어 future image를 복원한다.

<PaperFigure src="/moto/figure-02.png" alt="Moto — Latent Motion Tokens 원문 Figure 2: tokenizer, next-motion pretraining, action/motion co-fine-tuning과 attention mask." caption="Figure 2 · PDF v4 p.3. tokenizer, next-motion pretraining, action/motion co-fine-tuning과 attention mask." />

M-Former는 4 layers·hidden 768·12 heads, ViT decoder는 12 layers·hidden 768·12 heads·patch 16이다. **8개 quantized embedding을 concatenate한 뒤 MLP로 하나의 conditioning token**을 만들고 current patch feature에 더한다. codebook 128은 128개 실제 robot action의 고정 사전을 의미하지 않으며 sequence 공간은 최대 `128^8` 조합이다.

논문 objective는 future image pixel reconstruction MSE와 codebook/commitment loss다. 공개 예제는 frozen MAE ViT-L을 image encoder로 사용한다. tokenizer config에 LPIPS weight1도 있지만 `forward`에서 LPIPS를 `torch.no_grad()`로 계산해 scalar total에 더하므로, 이 항이 reconstruction으로 gradient를 보내는 perceptual training loss라고 해석하지 않는다. tokenizer 학습 이후에는 고정해 video transition에 motion pseudo-label을 만든다. future frame은 label 생성·tokenizer 학습용이며 배포 때 관측하지 않는다.

<PaperFigure src="/moto/table-04.png" alt="Moto — Latent Motion Tokens 원문 Table 4: M-Former·ViT decoder·VQ codebook의 실제 layer/head/dimension." caption="Table 4 · PDF v4 p.14. M-Former·ViT decoder·VQ codebook의 실제 layer/head/dimension." />

### 2. Moto-GPT pretraining

language token·초기 image token 뒤에 motion sequence를 붙이고 `-sum log p(m_i | instruction, initial image, m_<i)`로 next-token CE를 학습한다. GPT backbone은 12 layers·hidden 768·12 heads, 약 98M parameters다. 이는 frozen T5·ViT까지 합친 전체 pipeline parameter 수가 아니다.

훈련 sample은 초기 프레임과 두 transition까지의 짧은 영상 구조를 사용한다. 각 transition을 8 token으로 나타내면 ViT의 196 patch보다 작은 motion sequence로 이후 변화를 표현할 수 있다. 그러나 압축 비율이 그대로 실행 속도 배수로 바뀌지는 않는다.

<PaperFigure src="/moto/table-06.png" alt="Moto — Latent Motion Tokens 원문 Table 6: GPT backbone과 2-layer·hidden 384 action head." caption="Table 6 · PDF v4 p.15. GPT backbone과 2-layer·hidden 384 action head." />

### 3. Action·motion co-fine-tuning

motion group 뒤에 learnable action query를 놓고 실제 action chunk를 병렬로 예측한다. causal mask는 action token이 motion prediction에 정보를 누출하지 않게 구성한다. action query가 motion token을 보는 attention은 학습 때 50% 확률로 mask한다.

배포에는 두 가지 선택이 있다. motion을 생성하고 action query가 이를 참고하는 경로, 또는 motion 위치를 padding하고 attention을 전부 mask하여 serial motion generation 없이 action을 얻는 경로다. masked path도 pretraining된 GPT와 학습된 action head를 사용한다.

paper objective는 motion CE + position/rotation SmoothL1 + gripper BCE다. Google robot의 continuous gripper는 SmoothL1을 쓴다. **공개 trainer의 total loss는 `100 * arm_loss + gripper_loss + motion_loss`**여서 paper에 표시된 단순 합과 coefficient를 구분한다.

## Training Recipe

| 단계 | PDF recipe |
| --- | --- |
| Tokenizer | OXE 350k steps, CALVIN 150k. batch 256, 4×40GB GPU, AdamW lr 1e-4·WD 1e-4, cosine, warmup 1000 |
| Frame gap | RT-1 3 frames, 다른 robot은 FPS 보정. CALVIN 5, human SSV2 6 |
| GPT pretraining | 10 epochs, 8×40GB GPU, batch 512, AdamW lr 1e-4·WD 1e-4, cosine, warmup 1 epoch |
| Action fine-tuning | 4×40GB GPU. RT-1 3 epochs, CALVIN 18 epochs |
| 실물 | tokenizer 추가 500 steps. OXE+90 demo GPT 추가 5 epochs, action fine-tuning 20 epochs |

## 실험과 결과

### Token이 motion 정보를 보존하는가?

CALVIN의 34 task semantic classifier에서 초기 frame만 쓰면 accuracy 0.292, 이를 8번 반복하면 0.283, 초기+7개 실제 future frame은 0.828, 초기+7개 latent motion chunk는 **0.797**이다. motion code가 단순 이미지 반복 이상의 task 정보를 담는다는 평가이며, 실제 로봇 success rate가 아니다.

### 실물·human video

실물에서 Moto는 Pick/Close/Disassembly **70/70/40%**, motion 없이 학습한 모델은 **10/30/30%**, 평균 60 vs 23.33%다. 각 task 10회라 변화가 10 percentage points 단위다. distractor 조건 30 vs 10%, novel object 조건 40 vs 10%도 작은 평가이며 광범위한 robustness를 보장하지 않는다.

### Ablation·trajectory likelihood·imagined planning

Moto-IML은 motion prediction objective를 제거하고, Moto-DM은 action fine-tuning에서 motion sequence를 버린다. 두 variant는 full co-fine-tuning보다 낮지만 일부 단계에서는 scratch보다 높다. 따라서 tokenizer·pretraining의 transfer와 fine-tuning objective 유지 효과를 따로 읽어야 한다.

공식 repository는 tokenizer, pretraining, downstream adaptation·evaluation code와 checkpoint 안내를 제공한다. 공개 config의 경로·epoch/lr를 논문 실험의 확정 config로 간주하지 않는다. checkpoint 다운로드·로봇/시뮬레이터 실행은 이 노트에서 수행하지 않았다.

## 한계와 주의

- latent의 motion 의미는 reconstruction·classifier·qualitative transfer에서 지지되지만 causal physical action의 유일성을 보장하지 않는다.
- target robot action labels, frozen pretrained language/vision encoder를 사용한다.
- masked runtime이 motion autoregression 비용을 줄일 수 있어도 모든 setting의 control Hz·GPU latency를 일반화할 수 없다.
- drawer close·CALVIN 5-chain에서 더 강한 baseline이 남고 실물은 task당 10회다.
- imagined video, trajectory likelihood, top-K accuracy는 실제 task completion과 서로 다른 평가다.

## Citation Trail

[LAPA](../lapa-latent-action-pretraining/)와 함께 video→latent pseudo-label→policy 경로를 읽되 downstream head·loss 유지 차이를 비교한다. RT-1/RT-2-X/OpenVLA는 직접 action-label pretraining baseline, SuSIE는 video-generation 기반 planning, GR-1/RoboFlamingo는 multimodal policy transfer 기준선이다.

[LAOM](../laom-latent-action-supervision/)은 nuisance dynamics가 motion code에 섞일 수 있음을 검증하고, [UniVLA](../univla-task-centric-latent-actions/)는 task-centric disentangling을 시도한다. [LARA](../lara-latent-action-representation-alignment/)의 latent refinement는 Moto를 downstream 평가에 사용하지만 Fractal subset으로 수정한 protocol이므로 위 OXE 결과와 동일 실험이 아니다. [전체 안내](../latent-action-models/)에서 읽기 경로를 확인한다.
