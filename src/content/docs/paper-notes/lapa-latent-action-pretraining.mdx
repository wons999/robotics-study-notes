## 한 줄 요약

**영상 사이의 변화를 discrete latent action으로 압축하고 이를 예측하도록 VLM을 사전학습한 뒤, target robot의 실제 action head로 교체해 적은 시연으로 제어를 학습한다.** latent code를 그대로 고정된 로봇 명령 사전에 넣는 배포 방식과 구분해야 한다.

## 문제의식

로봇마다 joint·end-effector action 형식이 다르고 teleoperation 데이터 수집은 비싸다. LAPA는 영상의 현재 상태와 이후 상태가 보여주는 변화로 공통 pretraining target을 만든다. VPT처럼 먼저 action-label 데이터로 IDM을 학습하는 방식과 달리, 첫 tokenizer 학습에는 실제 action label을 쓰지 않는다.

그러나 action-label-free는 모든 supervision이 없다는 뜻이 아니다. policy pretraining에 image와 language instruction을 사용하고, LWM의 기존 multimodal pretraining을 출발점으로 삼으며, target fine-tuning에서는 실제 robot action label이 필요하다.

Cross-task는 pretraining에 없던 task를 zero-shot으로 실행하는 설정이 아니라, 다섯 task로 pretrain한 모델을 Separate 하나에 fine-tuning한 뒤 나머지 task 능력이 남는지 평가한다.

SIMPLER의 100개는 실물 teleoperation 100개가 아니다. 인간 영상만 쓰는 실험도 robot label이 없는 pretraining 이후에는 target robot의 labeled demonstration을 사용한다. Separate cross-task adaptation은 다른 조건보다 더 많은 시연을 사용하므로 숫자만으로 동일 budget 전이를 비교하면 안 된다.

## 방법론

### 1. Latent Action Quantization

현재·미래 프레임을 `x1, x2`라고 하자. C-ViViT 계열 spatial encoder와 causal temporal encoder에서 변화 표현을 얻고, discrete codebook으로 quantize한 `z`를 만든다. decoder는 현재 프레임과 `z`를 받아 미래 프레임을 MSE로 복원한다. 정보 병목을 두어 미래 이미지 전체를 latent에 그대로 복사하기 어렵게 하는 설계다.

NSVQ는 가장 가까운 code `q`와 원래 embedding `d`의 거리로 Gaussian noise 크기를 정한다. 학습 시 `d_hat = d + (||d-q|| / ||v||) v`를 사용하고 inference에서는 code lookup을 사용한다. 일반 VQ-VAE의 straight-through/commitment recipe와 같은 것으로 설명하지 않는다.

<PaperFigure src="/lapa/figure-08.png" alt="LAPA — Latent Action Pretraining 원문 Figure 8: C-ViViT encoder, discrete latent, NSVQ와 현재 프레임을 조건으로 하는 spatial decoder의 연결." caption="Figure 8 · PDF v2 p.15. C-ViViT encoder, discrete latent, NSVQ와 현재 프레임을 조건으로 하는 spatial decoder의 연결." />

공식 LAQ config는 image 256, patch 32, hidden 1024, spatial/temporal depth 각각 8, 16 heads·head dim 64, code dim 32, shared codebook 8, latent sequence 4다. 따라서 한 transition은 **8개 후보 중 선택한 token 네 개**로 표현되어 가능한 조합은 `8^4 = 4096`이다. 서로 독립된 실제 action 4096개를 의미하지 않는다. Language Table 기본 설정은 sequence 1·vocab 8이며 같은 용량으로 일반화할 수 없다.

### 2. Latent pretraining

LAQ를 고정하고 robot/human video를 latent pseudo-label로 relabel한다. LWM-Chat-1M 7B가 현재 image·instruction에서 latent sequence를 cross-entropy로 예측한다. vision encoder는 고정하고 language model을 학습한다. human data에서 로봇 action label을 제거했다고 language annotation까지 제거한 것은 아니다.

### 3. 실제 action adaptation과 inference

latent head를 버리고 실제 EEF action head를 새로 붙인다. continuous action의 각 차원을 equal-frequency bin으로 discretize하고 action-label target dataset에서 fine-tuning한다. 7D manipulation 배포 때 현재 RGB·instruction → action token → bin 중간값을 통한 EEF delta·gripper → robot controller 순서로 실행한다. Language Table은 2D action이며 direction language를 먼저 출력하는 별도 recipe를 사용한다. 7D 실험에서는 그 이득이 inference 비용보다 작아 language direction을 생성하지 않았다고 Appendix B가 설명한다.

이 경로에는 실제 미래 RGB가 없다. Appendix의 latent decoder를 계속 쓰는 대안은 성능이 더 낮았으며, 주 결과는 **head replacement**다. 예측된 미래 이미지를 다시 policy에 넣는 qualitative rollout은 배포 control loop와 별도다.

## Training Recipe

| 단계 | 논문·공식 공개 recipe |
| --- | --- |
| LAQ 공개 script | batch 64, Adam 계열 lr 1e-4, 100005 steps, frame offset 30 설정. 데이터 FPS·논문 실험과 동일한 조건이라고 자동 간주하지 않음 |
| 7B pretraining 논문 | 8 H100, batch 128, 약 34시간, 1 epoch |
| 현재 Open-X script | AdamW lr 2e-5 constant, weight decay 0, warmup 0, max sequence 384, global batch 256. 논문의 batch 128과 다름 |
| target fine-tuning script | real global batch 128, lr 2e-5, image augmentation. action vocab real 256 / SIMPLER 245 설정 |
| 비교 계산량 | LAPA 약 272 H100-hours vs OpenVLA 21500 A100-hours. 저자의 30–40배 추정은 H100/A100 성능 환산 가정에 의존 |

34시간은 기존 LWM backbone 학습 비용을 포함한 전체 생애주기 비용이 아니다. ActionVLA는 같은 LWM 기반의 action-supervised baseline이며 OpenVLA의 backbone·학습 epoch와 모두 같지 않다. token accuracy 학습 curve에서 LAPA 1 epoch, ActionVLA 3 epoch, OpenVLA 30 epoch를 직접 동일 실험으로 해석하지 않는다.

## Appendix Notes

Appendix A는 LAQ architecture·NSVQ, B는 데이터·환경, C는 baseline adaptation, D는 distribution·paired 비교, E는 latent 분석, F는 추가 ablation, G는 task별 sim/real 결과을 보강한다. 위 본문에 전체 표·그림을 배치했다. UniPi는 video planner를 action으로 연결하고 VPT는 action-supervised inverse model의 pseudo-label을 사용한다. ActionVLA는 LWM backbone을 맞춘 직접 action pretraining 기준선이라 OpenVLA와 동일 이름의 baseline이 아니다.

실물 per-trial 표는 partial credit·strict·reaching을 모두 남기며 “spicy object” 같은 instruction은 기존 task의 semantic variation이다. long-window 악화, grasp/placement 병목, camera-motion latent가 이 논문의 다음 질문을 만든다.

## 한계와 주의

- video-only pretraining 이후에도 target action labels와 기존 VLM 지식이 필요하다.
- task·embodiment 전이와 동일 로봇의 unseen instruction 일반화는 다른 실험이다.
- 실물 54회는 partial score와 strict success가 다르며 Pick-and-Place에서는 강한 action-label baseline이 우세하다.
- camera/background nuisance, 낮은 code capacity, grasp 정밀도 문제는 사전학습 규모만 늘려 해결되었다고 보기 어렵다.
- 공개 recipe와 paper recipe가 완전히 같지 않고, GPU-hours 비교도 동일 hardware/총비용 비교가 아니다.

## Citation Trail

VPT는 action-supervised IDM으로 video를 relabel하는 비교 경로, UniPi는 language-conditioned video planning, ActionVLA/OpenVLA는 실제 action label 기반 pretraining의 기준선이다. [LAPO](https://arxiv.org/abs/2312.10812)는 observation transition에서 inverse/forward dynamics를 학습하는 기반 흐름이다.

후속 [Moto](../moto-latent-motion-tokens/)는 motion prediction loss를 action fine-tuning에도 유지한다. [UniVLA](../univla-task-centric-latent-actions/)는 task-centric code와 contextual decoder를 사용하고, [LAOM](../laom-latent-action-supervision/)은 nuisance·action supervision의 역할을 분석한다. [LARA](../lara-latent-action-representation-alignment/)는 frozen pseudo-label 단계를 넘어 LAM과 VLA representation을 공동 정렬한다. 전체 연결은 [Latent Action Model 안내](../latent-action-models/)에서 비교한다.
