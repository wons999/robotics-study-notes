# Molmo Model Family

## 역할

이 문서는 AllenAI Molmo 계열 중 robot policy, simulation data scaling, action reasoning과 직접 연결되는 항목을 빠르게 잡기 위한 family overview다. 개별 논문이나 release의 기술 detail은 하위 상세 Survey 문서에서 다룬다.

핵심 원칙은 다음과 같다.

- family overview는 얕고 넓게 정리한다.
- MolmoB0T, MolmoAct, MolmoAct2는 각각 별도 paper survey로 다룬다.
- Molmo2-ER는 MolmoAct2의 backbone component이므로 MolmoAct2 survey에서 우선 다루되, 필요하면 별도 model note로 분리한다.
- paper 수치, blog/release 수치, code 공개 범위를 섞지 않고 출처를 분리한다.

## 큰 흐름

Molmo family의 핵심 질문은 두 갈래다. 첫째, robot policy는 어떤 data scale과 simulation diversity로 real-world에 transfer되는가. 둘째, robot policy가 행동 전에 무엇을, 어떤 형식으로 생각해야 하는가. MolmoB0T는 simulation-only data scaling과 flow action expert로 첫 질문을 밀고, MolmoAct/MolmoAct2는 depth token, visual trace, adaptive reasoning, flow expert로 두 번째 질문을 확장한다.

| 축 | MolmoB0T | MolmoAct | MolmoAct2 |
| --- | --- | --- | --- |
| 중심 질문 | simulation-only data scaling으로 sim-to-real이 가능한가 | action 전에 spatial reasoning trace를 생성하면 좋은가 | reasoning model을 실제 배포 가능하게 빠르고 open하게 만들 수 있는가 |
| data | MolmoSpaces procedural simulation, 1.7M trajectories | MolmoAct Dataset 10K+ trajectories + action reasoning data | BimanualYAM 720h, filtered DROID, SO100/101, Molmo2-ER corpus |
| reasoning representation | language + RGB/proprio/action, optional point conditioning | depth perception tokens, visual reasoning trace, action tokens | Molmo2-ER + adaptive depth tokens + flow action expert |
| action interface | DiTX-style flow matching action head, π0/SPOC variants | discrete autoregressive action tokens | discrete OpenFAST pretrain + continuous flow-matching post/fine-tune |
| deployment target | DROID/Franka, RB-Y1 zero-shot sim-to-real | LIBERO, SimplerEnv, real-world fine-tuning, steering | DROID/Franka, SO100/101, bimanual YAM, LIBERO, RoboEval |
| bottleneck | simulation-to-real gap과 data diversity | reasoning chain latency | flow expert/KV conditioning/adaptive depth로 latency와 deployability 개선 |

## 읽는 순서

1. [ECoT Family](../ecot/)를 먼저 보고 embodied reasoning의 큰 흐름을 잡는다.
2. [MolmoB0T](./molmobot-large-scale-simulation/)로 simulation-only data engine과 flow-action policy baseline을 본다.
3. [MolmoAct](./molmoact-action-reasoning-models/)로 depth/visual trace/action token 구조를 본다.
4. [MolmoAct2](./molmoact2-real-world-deployment/)로 OpenFAST, flow expert, adaptive depth, real-world deployment 결과를 본다.
5. [PI Model Family](../pi/)와 비교해 FAST/action tokenization과 flow matching action expert의 공통점과 차이를 정리한다.

- MolmoB0T/MolmoAct/MolmoAct2 하위 문서는 PDF figure/table inventory와 official code/data 공개 범위를 함께 확인한다.
