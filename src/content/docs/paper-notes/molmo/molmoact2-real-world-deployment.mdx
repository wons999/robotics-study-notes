## 한 줄 요약

MolmoAct2는 MolmoAct의 spatial reasoning을 유지하되, Molmo2-ER backbone, open FAST tokenizer, flow-matching action expert, per-layer KV-cache conditioning, adaptive depth reasoning을 결합해 실제 로봇 배포 속도와 성능을 개선한 open VLA다.

![MolmoAct2 overview](/molmoact/molmoact2-fig01-overview.png)

## MolmoAct 대비 개선 축

| 축 | MolmoAct | MolmoAct2 |
| --- | --- | --- |
| Reasoning backbone | Molmo 기반 ARM | Molmo2-ER: 3.3M embodied-reasoning corpus로 specialize-then-rehearse |
| Data | 10K+ MolmoAct Dataset + OXE subset | BimanualYAM 720h, filtered DROID, SO100/101, BC-Z/Fractal/Bridge 등 |
| Action interface | discrete action token 중심 | pretrain은 discrete OpenFAST token, post/fine-tune은 flow-matching continuous action expert |
| Conditioning | autoregressive reasoning chain | per-layer KV conditioning bridge로 VLM context를 action expert에 전달 |
| Depth reasoning | depth token을 매번 예측 | MolmoAct2-Think: scene change region만 adaptive depth token re-prediction |
| Latency | blog 기준 6,700 ms/action call | base 180 ms, Think 790 ms/action call; predecessor 대비 최대 37x faster |

## Dataset

| 데이터 | 규모/역할 |
| --- | --- |
| MolmoAct2-BimanualYAM | 720 hours teleoperated bimanual YAM trajectories, open bimanual tabletop/household data |
| MolmoAct2-DROID | quality-filtered Franka subset of DROID |
| MolmoAct2-SO100/101 | low-cost SO-100/SO-101 community LeRobot subset |
| Fractal / BC-Z / Bridge | tokenizer/control vocabulary coverage 확장 |
| Molmo2-ER corpus | 3.3M embodied-reasoning samples, pointing/object detection/spatial/multi-image/video reasoning |

Blog는 MolmoAct1이 22시간/10.6K trajectories였던 반면 MolmoAct2-BimanualYAM은 700시간 이상으로 30x 이상의 robot data를 제공한다고 설명한다. 또한 instruction labels를 open VLM으로 re-annotate해 unique labels를 약 71K에서 146K로 늘렸다고 보고한다.

## Model Architecture

MolmoAct2는 세 단계 training pipeline을 둔다.

| Stage | 역할 |
| --- | --- |
| MolmoAct2-Pretrain | Molmo2-ER를 discrete autoregressive robot policy로 적응. state token + OpenFAST action token을 next-token prediction으로 학습 |
| MolmoAct2-Post | continuous flow-matching action expert를 graft하고 VLM per-layer KV conditioning으로 연결 |
| Embodiment fine-tuning | YAM, DROID, SO100/101, LIBERO 등 target embodiment/task에 post checkpoint를 빠르게 적응 |

OpenFAST tokenizer는 one-second action trajectory를 frequency-domain transform, quantization, BPE로 2048-token action vocabulary에 매핑한다. Table 2 기준 tokenizer training mixture는 BimanualYAM 30%, SO100/101 30%, DROID 30%, Fractal 3.33%, BC-Z 3.33%, Bridge 3.33%다.

Flow expert는 DiT-style transformer이며, flow matching objective로 continuous action chunk를 denoise한다. 논문은 final hidden state 하나로 VLM context를 압축하지 않고, per-layer KV conditioning을 사용해 action expert가 VLM의 층별 context를 더 풍부하게 쓰도록 한다.

## MolmoAct2-Think

MolmoAct2-Think는 depth token을 완전히 제거하지 않고 adaptive하게 쓴다. 매 timestep마다 전체 depth grid를 다시 예측하는 대신, scene change가 있는 cell만 새 depth token을 생성하고 static region은 cached code를 재사용한다. Blog 기준 full dense depth-token prediction 대비 17% speedup을 보고한다.

이 설계는 ECoT-Lite/ERVLA와 같은 “test-time reasoning 제거”와는 다르다. MolmoAct2-Think는 reasoning을 유지하되, 필요한 region에만 depth reasoning을 써서 latency를 줄이는 hybrid route다.

## 한계와 주의

논문/blog가 직접 밝힌 약점은 두 가지다.

- Continuous closed-loop reactive policy가 아니라 10-30 moves chunk를 계획하고 실행하므로, chunk 중간 unexpected obstacle에 즉시 재계획하지 못한다.
- Out-of-the-box는 주로 SO-100, bimanual YAM, Franka처럼 많이 학습한 setup에 한정되며, humanoid나 dexterous hand에는 추가 training이 필요하다.
