## 한 줄 요약

**영상 변화 중 task와 무관한 부분을 먼저 codebook에 모으고, 나머지 task-centric latent를 robot·navigation·human video의 공통 policy target으로 사용한다.** target embodiment에 맞춘 action decoder와 labeled adaptation은 여전히 필요하다.

## 문제의식

영상 변화에는 robot action 외에 camera·배경·조명·사람의 다른 움직임이 섞여 있다. task instruction은 원하는 변화를 설명하지만 나머지 dynamics까지 설명하지 않는다. UniVLA는 language를 이용해 residual dynamics를 분리하고 task-centric code만 policy가 예측하게 한다.

“Act Anywhere”는 새로운 robot에 시연 없이 그대로 실행한다는 보장이 아니다. task-centric pretraining 후 해당 observation/action interface에서 LoRA와 decoder adaptation을 수행한다. human demonstration으로 새로운 skill을 inference 때 즉시 실행하는 경로는 future work로 제시된다.

## Dataset

pretraining은 Open-X single-arm EEF robot video, GNM indoor/outdoor navigation video, Ego4D human daily-activity video를 섞는다. robot action/proprio label은 이 구간의 policy target으로 쓰지 않는다. image·instruction과 기존 DINOv2/T5/VLM 지식이 supervision을 제공하므로 “무감독”을 지식·annotation이 전혀 없다는 뜻으로 읽으면 안 된다.

Table A-I는 30개 출처의 weighted mixture를 제시한다. Fractal 13.9%, BC-Z 8.8%, FMB 8.4%, Bridge 6.8%, Kuka 6.3% 등의 robot data와 RECON 8.9%, CoryHall 2.3%, SACSoN 3.5%의 navigation, Ego4D 3.0%가 함께 있다. 이 비율은 episode/frame 총수를 나타내지 않으며 별도 대규모 dataset을 이번 검토에서 내려받지 않았다.

<PaperFigure src="/univla/table-a-i.png" alt="UniVLA — Task-centric Latent Actions 원문 Table A-I: OXE·GNM·Ego4D 출처와 training mixture 비율 전체." caption="Table A-I · PDF v3 p.16. OXE·GNM·Ego4D 출처와 training mixture 비율 전체." />

LIBERO/CALVIN/R2R target dataset은 pretraining mixture에 포함하지 않았다고 설명한다. 반면 SIMPLER Bridge task는 Bridge pretraining과 분포가 겹치므로 완전히 held-out embodiment benchmark라고 보기 어렵다. R2R train 10819 / val-unseen 1839 episode이며 LLaVA-Nav 비교 수치는 100-episode subset 조건이라는 입력·분모 차이도 남는다.

## 방법론

### 1. Task-irrelevant latent를 먼저 학습

DINOv2 patch feature의 current/future 쌍과 T5 instruction embedding을 encoder·decoder에 준다. language가 task 관련 변화를 설명하고 작은 codebook이 남은 dynamics를 압축하도록 유도한다. pixel 대신 frozen DINO feature reconstruction MSE + VQ/commitment objective를 사용한다.

### 2. Task-centric codebook을 추가

stage 1 codebook을 가져와 고정하고 language conditioning을 제거한다. 새 query·codebook을 추가해 task 관련 dynamics를 담당하게 한다. 기존 task-irrelevant token과 새 task-centric token을 함께 decoder에 전달한다. policy pretraining에는 **새 task-centric token만** 사용한다.

<PaperFigure src="/univla/figure-02.png" alt="UniVLA — Task-centric Latent Actions 원문 Figure 2: language-conditioned stage 1과 language를 제거한 stage 2. task-irrelevant codebook과 새 codebook을 구분한다." caption="Figure 2 · PDF v3 p.4. language-conditioned stage 1과 language를 제거한 stage 2. task-irrelevant codebook과 새 codebook을 구분한다." />

이 설계는 disentangling을 유도하지만 task-irrelevant / task-centric이라는 이름 자체가 독립적인 인과 변수임을 증명하지는 않는다. old codebook을 freeze하는 것과 전체 encoder/decoder를 freeze하는 것은 다르다. 공개 stage 2는 old VQ의 gradient만 freeze하고 공통 encoder·decoder를 계속 학습한다. 다만 `code_restart=True`와 epoch-end `random_restart()`가 남아 있어 unused old code는 gradient 없이도 교체될 수 있다. 따라서 공개 구현의 old codebook을 완전히 불변인 dictionary로 단정하지 않는다.

**원문과 구현의 차이:** Section III-A의 prose는 decoder가 historical frame 없이 quantized token만 받는다고 설명하지만, Figure 2·수식과 공식 `lam.py`는 **current DINO feature를 decoder 조건으로 함께 사용**한다. 이를 조용히 하나의 설명으로 통일하지 않고 실제 공개 구현 기준을 명시한다.

### 3. Latent policy와 contextual action decoding

VLM vocabulary에 `<ACT_1>`–`<ACT_16>`을 추가하고 4개의 task-centric token CE를 학습한다. policy pretraining은 visual encoder·language model·head를 함께 optimize한다. LAM 내부 frozen DINO/T5와 policy의 trainable visual encoder를 구분한다. 표현 가능한 token 조합은 `16^4 = 65536`이며 이는 물리적으로 구별되는 control command 개수가 아니다. OpenVLA의 7개 action dimension별 256-bin tokenization과 공간 구조가 다르다.

target adaptation은 LoRA와 contextual decoder를 학습한다. decoder는 latent token hidden state와 현재 visual feature를 각각 attention pooling해 실제 action을 출력하며, 실물 설정은 proprio projection도 더한다. CE와 실제 action L1을 함께 사용한다. 직전 4-token group을 prompt history에 추가해 장기 task를 보강한다.

배포 loop는 현재 RGB·instruction·직전 code → 4-token autoregression → contextual decoder → normalization 복원·gripper convention 변환 → action 실행이다. 실제 future RGB는 이 loop에 들어가지 않는다. 처음 보는 action space는 decoder와 target label이 필요하다.

## 모델 구조와 Training Recipe

| 구성·구간 | 논문 또는 공개 config |
| --- | --- |
| LAM 공개 config | image 224 / DINOv2 ViT-B/14-reg 256 patch, frozen T5-base. hidden 768, encoder/decoder 각 12 layers·12 heads |
| Latent | code dim 128, codebook 16, query 4. 두 stage의 old/new codebook은 서로 별도 |
| LAM 공개 학습 | AdamW lr 1e-4·WD 1e-2, batch 64/device × 8 = 512, 20 epochs, mixed precision 16, clip 0.1, commitment beta .25 |
| Full policy pretraining | 32 A100, global batch 1024(32/device), constant lr 2e-5, 20k steps·약 30시간 |
| Human/Bridge subset | PDF는 8 GPU·batch 258·약 200 A100 GPU-hours로 기록. 258을 임의로 256으로 수정하지 않음 |
| LIBERO adaptation | batch 128, 보통 30k steps, Long 40k. suite별 action labels |
| CALVIN adaptation | 100k steps, batch 128, 처음 80k lr 1.5e-4 이후 1.5e-5. OpenVLA 비교는 chunk 8·200k steps |
| Real decoder | 8-head attention pooling·hidden 512, proprio 7→512 MLP, 12×7 action chunk |

<PaperFigure src="/univla/table-a-vi.png" alt="UniVLA — Task-centric Latent Actions 원문 Table A-VI: 실물 decoder의 pooling·projection·12.6M parameter 설정." caption="Table A-VI · PDF v3 p.18. 실물 decoder의 pooling·projection·12.6M parameter 설정." />

introduction의 decoder **10.8M**과 실물 Table A-VI의 **12.6M**, trainable LoRA 포함 **123M**은 서로 다른 범위로 기록한다. 작은 decoder만의 parameter 수로 전체 target training 규모를 대신하지 않는다. “1/20 compute” claim은 기존 VLM pretraining이나 모든 tokenizer 학습 비용까지 맞춘 전체 생애주기 비용 비교가 아니다.

## 한계와 주의

- task-centric code는 실험적 분리이며 causal disentanglement의 보장은 아니다.
- novel embodiment의 action decoder·LoRA에는 target action-label supervision이 필요하다.
- coarse video interval·language granularity가 미세 manipulation을 제한하고 SIMPLER stacking이 약하다.
- navigation oracle SR, manipulation SR, 실물 partial score를 하나의 평균으로 합칠 수 없다.
- paper prose/table/teaser 간 여러 수치·architecture 불일치를 위에 보존했다. unknown trial denominator를 추정하지 않았다.
