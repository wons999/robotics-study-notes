# 논문 Survey

이 섹션은 로보틱스, robot learning, VLA, tactile policy, flow/diffusion action model 관련 논문을 깊게 읽고 재사용 가능한 형태로 정리하는 공간이다. 단순 요약보다 문제 설정, 데이터셋, 방법론, 모델 구조, 학습 recipe, 실험 결과, appendix, 코드 구현 차이를 함께 남기는 것을 기준으로 한다.

## 섹션 역할

| 항목 | 설명 |
| --- | --- |
| 목적 | 논문을 다시 열지 않아도 핵심 방법론과 수치, 구현 포인트를 확인할 수 있게 정리한다. |
| 포함 자료 | 논문별 Survey, model family overview, citation 흐름, appendix notes, 공식 코드 확인 메모 |
| 작성 기준 | `rules/survey.md`의 high-effort Survey 규칙을 따른다. |
| 세미나와의 관계 | 발표 흐름은 `세미나` 섹션에 두고, 근거와 상세 분석은 이 섹션에 둔다. |

## 최근 집중 Survey

| Survey | 핵심 질문 |
| --- | --- |
| [DexMimicGen](./dexmimicgen-bimanual-data-generation/) | 소수의 양팔·다지손 demonstrations를 팔별 subtask로 나누고 coordination/order를 보존하면서 simulation data로 scale할 수 있는가 |
| [ThinkProprio](./thinkproprio-state-grounded-token-selection/) | proprioception을 action head의 late condition이 아니라 pre-VLM visual-token query로 쓰면 성능과 latency를 함께 개선할 수 있는가 |
| [ECoT Reasoning Family](./ecot/) | embodied chain-of-thought가 explicit reasoning, training-only supervision, spatial trace, adaptive depth reasoning으로 어떻게 발전했는가 |
| [Molmo Model Family](./molmo/) | MolmoAct/MolmoAct2가 spatial action reasoning과 real-world deployment를 어떻게 연결하는가 |
| [MolmoAct2](./molmo/molmoact2-real-world-deployment/) | open action reasoning model을 real-world deployment에 맞게 flow expert, OpenFAST, adaptive depth로 어떻게 재설계했는가 |
| [MolmoAct](./molmo/molmoact-action-reasoning-models/) | depth perception token과 visual reasoning trace가 VLA action prediction 앞에서 어떤 spatial reasoning 역할을 하는가 |
| [ECoT-Lite](./ecot/ecot-lite-efficient-embodied-reasoning/) | embodied CoT의 이득을 test-time reasoning 없이 training recipe로 가져갈 수 있는가 |
| [T-Rex](./t-rex-tactile-reactive-dexterous-manipulation/) | 느린 VLA reasoning과 빠른 tactile correction을 어떻게 한 policy 안에서 나눌 것인가 |
| [VTLA](./vtla-preference-learning-insertion/) | insertion manipulation에서 vision-tactile-language-action fusion과 DPO preference learning이 sim-to-real 성능을 어떻게 바꾸는가 |
| [MolmoB0T](./molmo/molmobot-large-scale-simulation/) | real robot demonstration 없이 simulation-only data scale과 diversity만으로 manipulation sim-to-real을 어디까지 밀 수 있는가 |
| [3D Diffusion Policy](./3d-diffusion-policy-dp3/) | 2D image diffusion policy의 representation bottleneck을 sparse 3D point cloud로 줄일 수 있는가 |
| [Diffusion Policy Policy Optimization](./dppo-diffusion-policy-policy-optimization/) | pretrained diffusion policy를 PPO로 fine-tune해 long-horizon recovery와 sim-to-real을 개선할 수 있는가 |
| [GR00T Model Family](./groot/) | GR00T N1/N1.5/N1.6/N1.7이 backbone, data, action interface, deployment에서 어떻게 달라지는가 |
| [PI Model Family](./pi/) | pi.website의 π0, π0-FAST, OpenPI, HI Robot, π0.5, Knowledge Insulation, RTC, π*0.6, MEM, RLT, π0.7 흐름이 어떻게 이어지는가 |
