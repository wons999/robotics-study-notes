# 노트

이 섹션은 완결된 개별 논문 해설보다 **여러 근거를 연결해 다음 판단과 실험으로 넘기는 작업 문서**를 모은다. 논문별 원문·수치·appendix를 깊게 정리한 글은 `논문 Survey`에 두고, 여기서는 비교, 설계안, 구현 관찰, 진행 중인 가설과 실제 실험 기록을 다룬다.

## 카테고리 역할

| 문서 성격 | 담는 내용 |
| --- | --- |
| 방법 비교 | 서로 다른 논문의 전제, evidence, 비용, failure mode를 같은 축에 놓고 비교 |
| 연구 설계 | 통제 변수, baseline, metric, ablation, 최소 실험표와 해석 기준 |
| 구현 판단 | 공개 코드에서 확인한 범위, 재현 시 필요한 구성요소, 도입 순서 |
| 실험 기록 | 질문, exact setup, code/config, 결과, 실패 원인과 생각이 바뀐 지점 |
| 후속 질문 | 논문이 답하지 않은 부분과 다음에 검증할 가설 |

Survey의 headline 수치를 단순 재정렬하는 문서가 되지 않도록, **원문 근거**, **현재 해석**, **후속 제안**을 구분한다. 서로 다른 benchmark 수치는 직접 ranking하지 않고, 비교 불가능한 조건 자체를 기록한다.

## 노트 기본 형식

| 항목 | 기록할 내용 |
| --- | --- |
| 질문 | 무엇을 결정하거나 검증하려는가 |
| 근거 | 논문, 코드, 관찰, 기존 결과 중 확인된 사실 |
| 비교 조건 | 고정해야 할 변수와 직접 비교할 수 없는 조건 |
| 현재 해석 | 근거에서 도출한 판단과 불확실성 |
| 설정 | dataset, model, config, seed, hardware, output path |
| 결과 | metric, 실패 사례, 예상과 달랐던 지점 |
| 다음 단계 | 최소 후속 실험 또는 추가 확인 항목 |
| 상태 | 아이디어 / 설계 중 / 실행 중 / 검증됨 / 보류 |

실제 실험을 실행한 문서에는 재현 가능한 config와 artifact 위치를 남긴다. 아직 실행하지 않은 비교·설계 문서는 결과처럼 서술하지 않고 `제안`, `가설`, `확인 필요`를 명시한다.

## 아이디어 백로그

- RoboSplat 3D view augmentation과 RoboEngine-style background generation의 controlled `3D-only / 2D-only / hybrid` 비교.
- 2-link damped least-squares IK.
- Joint-space PD vs task-space impedance toy example.
- 간단한 contact/friction cone 시각화.
- 작은 simulated reaching task에서 behavior cloning.
