## 핵심 질문

데이터를 늘린 효과와 scene·embodiment 다양성의 효과는 어떻게 다른가?

## 권장 읽기 순서

1. [Open X-Embodiment](../../paper-notes/open-x-embodiment-rt-x/): 다양한 robot data의 공통 interface.
2. [HPT](../../paper-notes/hpt-heterogeneous-pretrained-transformers/): heterogeneous state/action 처리.
3. [DexMimicGen](../../paper-notes/dexmimicgen-bimanual-data-generation/): 시연으로부터 simulation trajectory 생성.
4. [RoboSplat vs RoboEngine](../../experiments/robosplat-vs-roboengine-synthetic-augmentation/): 3D·2D 증강의 비교 설계.
5. [LARA](../../paper-notes/lara-latent-action-representation-alignment/): 영상 동역학 latent를 실제 action supervision과 공동 학습. OXE subset 구성·sampling·미래 frame target을 구분한다.

[Latent Action Model 읽기 안내](../../paper-notes/latent-action-models/): LAPA·Moto·LAOM·UniVLA·LARA에서 action-label-free pretraining과 target label·language supervision의 범위를 나눈다.

[LWD와 ALOE](../../paper-notes/lwd-aloe-vla-post-training/): mixed replay의 value target·human correction·fleet/iteration budget을 비교한다.

## 비교와 후속 검증

데이터 수, task coverage, camera, appearance, object pose를 분리합니다. 서로 다른 benchmark headline 수치를 하나의 순위로 합치지 않습니다.
